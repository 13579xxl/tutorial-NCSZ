# 物联网与互联网简介
万物互联，地球为村
## 物联网
“物联网”一词，在当今的生活中可谓是越来越常见了，随着科技的发展，这一概念也逐渐走入我们的生活当中，故而知晓和了解这一概念十分重要

物联网的定义如下：
> 物联网（英文：Internet of Things，缩写：IoT）起源于传媒领域，是信息科技产业的第三次革命。物联网是指通过信息传感设备，按约定的协议，将任何物体与网络相连接，物体通过信息传播媒介进行信息交换和通信，以实现智能化识别、定位、跟踪、监管等功能。

简单说，所谓物联网就是通过各类传感器来将现实世界与网络世界连接起来，从而更好的服务与人，比如感知当天天气（温湿度传感器）并给出出行建议发送到用户端，自动感知光照从而调节灯光亮度（光敏），等等。

这些看似科幻的内容，正在慢慢进入我们的生活中，而它们的背后，就是迅猛发展的物联网技术与人工智能技术。这些我们在本个手册中都会予以初步介绍，相信你也可以通过运用成熟的模块与库来制作出这类作品。

## 互联网
相比于物联网，互联网大家应该一点都不陌生，在百度上，给出的介绍如下：

>互联网（Internet），又称国际网络，是由众多计算机网络互联而成的全球性网络基础设施，以一组通用协议（如TCP/IP）相连，形成逻辑上的单一网络。

这段话当中涵盖的大部分术语我们并不陌生，如“计算机网络”、“TXP/IP”等我们都在上一节有过粗略的介绍。

其实根据这段话我们就可以简单提炼出，所谓互联网就是将全球许许多多网络连接起来形成的庞大网络，让大家可以实现全球数据的互联和共享，这就是所谓的互联网
